# Code of Conduct

## Our standard

Rivet contributors and maintainers are expected to make participation
welcoming, respectful, and constructive. Discuss ideas and evidence directly;
do not target people. Harassment, discrimination, threats, doxxing, and
deliberate disruption are not acceptable.

## Scope

This applies to issues, pull requests, reviews, discussions, commits,
screenshots, and other project spaces or events where someone represents Rivet.

## Enforcement

Report behavior that violates this standard privately to the project
maintainers through a GitHub Security Advisory or a private maintainer
contact. Include links or other context when safe to do so. Maintainers may
remove content, close discussions, or restrict participation when necessary to
protect the community.

Reports are handled as confidentially as practical. Retaliation against a
good-faith report is not acceptable.
