# Support

Rivet is an early, local-first alpha. Before opening a request, check the
[README](README.md), [ROADMAP](ROADMAP.md), [contributing guide](CONTRIBUTING.md),
and existing GitHub issues.

## Questions and usage help

Open a GitHub issue with the `question` label when the answer will help other
Rivet users. Include the Rivet version or commit, operating system and
architecture, the CLI/desktop/server surface, and the smallest sanitized
reproduction. Never include provider tokens, private keys, passwords, customer
repositories, or real hostnames.

## Bugs and feature requests

Use the repository's issue templates. Provide exact local commands and output,
and distinguish behavior that is working today from an experimental or planned
Jenkins compatibility boundary.

## Security

Do not report vulnerabilities publicly. Use a [private GitHub Security
Advisory](https://github.com/OthmaneBlial/Rivet/security/advisories/new) and
follow [SECURITY.md](SECURITY.md).

Rivet does not provide guaranteed response times or hosted support. Community
help is welcome, and reproducible local evidence makes reports actionable.
